## 如何参与

1. **勘误 / 建议**：开 Issue（可用模板「勘误与建议」）。
2. **补充素材 / 文稿**：Fork 后提交 PR，或先开 Issue 说明意图。
3. **案例线索**：注明论文作者、题名、刊名、年份与期号，便于回溯。

网站「开放共创」表单的内容，将由服务端整理为本仓库的 Issue 或 PR（实现细节见 [`docs/architecture.md`](./docs/architecture.md)）。
