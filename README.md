## 这本书是什么

公共政策每天都在安排亿万人的生活：入学、就医、就业、环保、数字治理……本教材不满足于背诵名词，而训练三种能力：

1. **看得清**：用概念与框架把模糊现象变成可分析的问题  
2. **做得动**：会用问题树、论证结构、成本收益等工具  
3. **说得明**：判断可被检验、可被反驳，并能回到一手文献  

全书坚持：**体系可教 · 材料可核 · 表达可读**。中国案例优先取自近年《中国行政管理》等期刊实证研究，引注规范，可回溯。

## 章内教学体例

每章按统一元件编排，便于课堂与自学：

| 元件 | 作用 |
|---|---|
| 学习目标 | 可测量的能力目标 |
| 章首导引 | 以真实问题开场 |
| 正文 + 微型知识块 | 概念辨析、思想实验、争鸣、数据一瞥等 |
| 中国案例专栏 | 以理论框架拆解可回溯的实证研究 |
| 理论前沿专栏 | 2010 年后研究议程 |
| 比较视野专栏 | 跨制度对照 |
| 方法工具箱 | 可操作步骤、适用条件与局限 |
| 本章小结 | 回应导引，并写明未决问题 |
| 思考与讨论 | 含操作题与争鸣题 |
| 延伸阅读 | 经典论文与专著，分必读 / 选读 |
| 关键术语 | 中英对照与一句话定义 |

## 如何参与共创

三种方式，任选其一：

1. **网站表单**（推荐给非 GitHub 用户）  
   首页 →「开放共创」→ 填写类型与说明，可上传 doc / xlsx / pdf / md / txt。

2. **GitHub Issue**  
   使用模板：[勘误与建议](./.github/ISSUE_TEMPLATE/errata.md) · [案例线索](./.github/ISSUE_TEMPLATE/case-lead.md)

3. **Pull Request**  
   Fork → 建分支 → 修改 `textbook/` 或文档 → 提 PR（见 [`CONTRIBUTING.md`](./CONTRIBUTING.md)）。

### 欢迎什么

- 错别字、术语不一致、引注著录问题  
- 概念表述与结构建议  
- 可核查的中国案例线索（作者、题名、刊名、年份与期号）  
- 可直接合并的补充文稿或图表说明  

### 暂不接受

- 无出处的大段改写  
- 期刊全文 PDF 批量上传  
- 与教材定位无关的推广内容
