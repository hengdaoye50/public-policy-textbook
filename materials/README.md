# 教材与专著资料

本目录收录编写过程中参照的**中文教材与中英文专著**电子文件（PDF/DOCX 等），供维护者核对表述与图源。

**不包含**期刊论文全文（如《中国行政管理》）。论文素材以书目与具引为准，见 [`references/参考文献.md`](../references/参考文献.md)。

## 使用说明

- 文件仅供课程教学与教材修订内部核对；再分发请遵守原版权方规定。
- 大文件经 Git LFS 存储，clone 后若缺文件请执行：`git lfs pull`。
- 目录结构与本地材料包 `相关教材与专著/` 一致。
